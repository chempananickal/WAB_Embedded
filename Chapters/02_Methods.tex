\chapter{Methods}

\section{Dataset}
The base dataset used in this project is a subset of the \gls{ZINC20} dataset \cite{zinc}, which contains 249,455 commercially available drug-like molecules and their corresponding \gls{logp} values.
Specifically, this subset was extracted at random from the entire \gls{ZINC20} dataset by G\'omez-Bombarelli et al. \cite{zinc20source}.

The \gls{logp} values within the \gls{ZINC20} dataset were calculated using Molinspiration's MiLogP algorithm, which calculates \gls{logp} based on group contributions \cite{molinspiration}.
Due to the limited availability of large datasets of experimentally confirmed \gls{logp} values for drug-like molecules, and due to the limited scope of this project, 
this computed \gls{logp} will be treated as the ground truth for the purposes of training and evaluating the machine learning model.

\section{Design}

Python \cite{python} version 3.12.13 served as the primary programming language for this project. 
The entire project was conducted on a laptop running Windows 11 25H2.

The dataset was randomly split into training (80\%), validation (10\%), and test (10\%) sets, 
with the random seed set to 42 to ensure reproducibility.

The input features for the model are 2048-bit Morgan fingerprints (radius 2) generated from the \gls{smiles} representations of molecules. 
The \gls{smiles} were canonicalized and the fingerprint bit vectors were generated using the RDKit \cite{rdkit} library in Python.

The machine learning model is a \gls{mlp} with a single hidden layer of 128 units, using a \gls{relu} activation function, 
followed by a linear output layer that predicts the \gls{logp} value.
Keras \cite{keras} was used as the high-level API for building and training the neural network, while TensorFlow \cite{tensorflow} served as the backend.
Model training was performed fully on the CPU using the \gls{adam} optimizer \cite{adam} and mean squared error (MSE) as the loss function. 
\begin{equation}
    \mathrm{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
\end{equation}
where $y_i$ is the true \gls{logp} value and $\hat{y}_i$ is the predicted \gls{logp} value for the $i$-th sample.

Early stopping was employed to prevent overfitting, monitoring the validation loss and restoring the best weights.
This meant that with a batch size of 256 and the TensorFlow random seed set to 42, the training converged after 12 out of a maximum of 20 epochs (see Figure \ref{fig:training_history}).

\section{ESP32 Deployment}

To reduce the model size, the final model was quantized to 8-bit integers using \gls{tflite}'s post-training quantization method. 
The resulting flatbuffer was saved as a .tflite file.

This .tflite file was then converted to a C array using a python tool that emulates the POSIX `xxd` command, 
and the resulting .cc and .h files, along with an API script, were built and flashed onto an \gls{esp32} microcontroller using ESP-IDF version 5.5.3.

All the necessary code files, along with Visual Studio Code specific instructions for setting up the ESP-IDF environment, building the project, and flashing the firmware, can be found in the supplementary materials.

ESP32 specifications \cite{esp32spec}:
\begin{itemize}
    \item Model: ESP32-WROOM-32D
    \item CPU: Dual-core Xtensa LX6 microprocessor, up to 240 MHz
    \item RAM: 520 KB SRAM
    \item Flash Storage: 4 MB
\end{itemize}

The accuracy of the model was then tested on the test set of 24,946 compounds by running inference on the ESP32 and comparing the predicted \gls{logp} values against the ground truth.
The measured performance metrics include mean absolute error (MAE), root mean squared error (RMSE), the coefficient of determination ($R^2$), and the Pearson correlation coefficient ($r$).
\begin{equation}
    \mathrm{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|
\end{equation}
\begin{equation}
    \mathrm{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2}
\end{equation}
\begin{equation}
    R^2 = 1 - \frac{\sum_{i=1}^{n} (y_i - \hat{y}_i)^2}{\sum_{i=1}^{n} (y_i - \bar{y})^2}
\end{equation}
\begin{equation}
    r = \frac{\sum_{i=1}^{n} (y_i - \bar{y})(\hat{y}_i - \bar{\hat{y}})}{\sqrt{\sum_{i=1}^{n} (y_i - \bar{y})^2 \sum_{i=1}^{n} (\hat{y}_i - \bar{\hat{y}})^2}}
\end{equation}
where $n$ is the number of samples, $y_i$ is the true \gls{logp} value, $\hat{y}_i$ is the predicted \gls{logp} value, $\bar{y}$ is the mean of the true \gls{logp} values, and $\bar{\hat{y}}$ is the mean of the predicted \gls{logp} values.
